# BikeMate

Мобильное приложение для велосипедистов: подбор и покупка запчастей, видео-гайды
по установке, покупка велосипеда, ИИ-помощник по ремонту и лента мест для катания.

## Стек

- **Expo (React Native) + TypeScript** — один код для iOS и Android.
- **expo-router** — файловая навигация, нижний tab bar.
- **Zustand** — локальное состояние (лента мест для катания).
- **Supabase** — хранилище фото для мест катания (опционально, есть локальный фолбэк).
- **Anthropic API (Claude)** — ИИ-чат по ремонту велосипеда (есть демо-режим без ключа).
- **react-native-webview** — встроенный плеер YouTube для видео-гайдов.

Дизайн — в стиле iOS: системный шрифт, скруглённые карточки, мягкие тени,
поддержка светлой и тёмной темы (следует системной настройке).

## Что работает уже сейчас (без ключей)

- Поиск запчастей по модели велосипеда — список предложений с маркетплейсов
  (Ozon, Wildberries, Avito, AliExpress) и видео-инструкция — **мок-данные**.
- Поиск, где купить велосипед — **мок-данные**.
- ИИ-чат — отвечает заготовленными ответами (скрип цепи, тормоза и т.д.).
- Лента мест для катания с лайками, добавление своего места с фото
  (фото сохраняется только локально на устройстве, пока не подключён Supabase).

## Какие API-ключи нужны для реальных данных

| Ключ | Для чего | Где получить |
|---|---|---|
| `EXPO_PUBLIC_ANTHROPIC_API_KEY` | Реальные ответы ИИ-помощника | https://console.anthropic.com/settings/keys |
| `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Облачное хранение фото мест катания | https://supabase.com/dashboard → создать проект → Project Settings → API |
| `EXPO_PUBLIC_YOUTUBE_API_KEY` | Реальный поиск видео-гайдов (сейчас используется один и тот же мок-видео) | https://console.cloud.google.com/apis/credentials → включить YouTube Data API v3 |

Маркетплейсы (Ozon, Wildberries, Avito, AliExpress) **не дают публичного API для
поиска цен** сторонним приложениям. Сейчас кнопки "где купить" открывают страницу
поиска по нужному запросу на сайте маркетплейса. Если нужны точные цены —
варианты: партнёрские/affiliate API (например, у AliExpress есть Affiliate API,
требует регистрации в партнёрской программе) или веб-поиск через ИИ с tool use.

> **Важно про безопасность:** переменные `EXPO_PUBLIC_*` попадают в собранное
> приложение и могут быть извлечены из APK/IPA. Для прототипа это нормально, но
> перед публикацией в стор перенесите вызовы Anthropic/YouTube на свой backend
> (например, Supabase Edge Function), который хранит ключи на сервере.

## Установка и запуск с нуля

1. Установите Node.js 18+ и npm.
2. Установите зависимости:
   ```bash
   npm install --legacy-peer-deps
   ```
   (флаг `--legacy-peer-deps` нужен из-за конфликта пиров между React 19 и
   web-зависимостями `expo-router`; на работу приложения это не влияет.)
3. Скопируйте `.env.example` в `.env` и при желании заполните ключи:
   ```bash
   cp .env.example .env
   ```
4. Запустите проект:
   ```bash
   npx expo start
   ```
5. Откройте приложение:
   - На телефоне — установите **Expo Go** (App Store / Google Play) и
     отсканируйте QR-код из терминала.
   - В симуляторе iOS (нужен Mac + Xcode) — нажмите `i` в терминале.
   - В эмуляторе Android (нужен Android Studio) — нажмите `a` в терминале.

## Структура проекта

```
app/                    экраны (expo-router, файловая навигация)
  (tabs)/               три вкладки нижнего таб-бара
    index.tsx           Запчасти
    bikes.tsx           Велосипеды
    spots.tsx           Места для катания
  chat.tsx              экран ИИ-чата
  spot/[id].tsx         детали места
  spot/new.tsx          добавление нового места
src/
  components/           переиспользуемые UI-компоненты (Card, IOSButton, ...)
  data/mock.ts          мок-данные маркетплейсов, видео, мест катания
  services/             anthropic.ts, supabase.ts — интеграции с внешними API
  store/                Zustand-хранилища
  theme/                цвета, типографика, отступы (светлая/тёмная тема)
  types/                общие TypeScript-типы
```
